梦工厂 - 使用说明

核心场景

常规赛事（队伍参赛）
  • 适合：5人队伍代表俱乐部/自由名单参赛
  • 规则：队长报名 → 队员确认入场费 → 10人满员开赛 → 胜方瓜分奖池
  • 入场费三档：500 / 1000 / 2000 梦币

参赛流程

  1. 队长报名：进入常规赛事 → 选择代表队伍 → 报名，队伍5人收到通知
  2. 队员确认：进入赛事详情 → 选入场费档位 → 确认入场，扣除梦币
  3. 开赛：10人满员后自动锁定，到达开赛时间正式开始
  4. 提交结果：开赛20分钟后可上传截图 + 胜方 + KDA数据
  5. 管理员结算：审核无误后发放奖池，胜方按入场费占比瓜分

奖池规则

  • 总奖池 = 10人入场费之和
  • 胜方5人按个人入场费占比瓜分总奖池
  • 败方5人入场费全损，无返还
  • 报名不足10人 → 自动取消 → 全额退费

新手指南

① 认证身价获得启动资金 → ② 寻找队友/联系俱乐部 → ③ 积极参与赛事 → ④ 比赛影响身价（胜+2%/败-2%，MVP+2%）→ ⑤ 查看榜单排名

两种运营模式：

💰 高价冲榜流：高价购入顶尖选手 → 组建豪华战队 → 比赛获胜涨身价 → 占据榜单前排

📈 低成本培养流：低价购入潜力选手 → 培养 → 身价上涨 → 卖给官方联梦（获得交易价80%提成）
