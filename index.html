浅梦训练赛 - 使用说明

核心场景

招募大厅（散人专用）
  • 适合：单人/带1-4个朋友，凑齐10人打训练赛
  • 规则：红蓝双方各5人，满10人后全员确认 → 正式成局
  • 发起招募可选三种模式：参赛/纯组织/带部分队友

招募大厅玩法

  1. 加入对局：选红蓝方+分路 → 报名
  2. 发起招募：设置时间、段位、模式 → 发布
  3. 满员确认：10人凑齐后，所有人需点击"能参加"确认
  4. 正式成局：全员确认后锁定，自动创建腾讯会议

确认阶段规则

  • 满10人后进入待确认状态，所有人会收到确认通知
  • 点击"能参加" → 标记为已确认，全员确认后自动成局
  • 点击"没时间" → 自动退出，招募恢复，其他人需重新确认
  • 开赛前10分钟若还有人未确认，自动清理未确认者并恢复招募

队伍系统

  • 可创建或加入队伍（最多7人）
  • 队长可邀请成员、踢人、转让、解散
  • 管理员也可代建队伍和调整成员

腾讯会议

  • 模式2（纯组织者）会自动创建会议
  • 其他模式下，发起人可手动创建会议

重要规则

  • 每条分路只能1人，全场最多10人
  • 可带朋友一起报名，无需注册多个账号
  • 满10人后进入确认阶段，未确认者不会占用位置
  • 确认成局后锁定，不再接受新报名
