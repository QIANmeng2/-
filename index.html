梦工厂 - 使用说明

核心场景

常规赛事（队伍参赛）
  • 适合：5人队伍代表俱乐部/自由名单参赛
  • 规则：队长报名 → 队员确认入场费 → 10人满员开赛 → 胜方瓜分奖池
  • 入场费三档：500 / 1000 / 2000 梦币

参赛流程

  1. 队长报名：进入常规赛事 → 选择代表队伍 → 报名，队伍5人收到通知
  2. 队员确认：进入赛事详情 → 选入场费档位 → 确认入场，扣除梦币
  3. 开赛：10人满员后自动锁定，到达开赛时间正式开始
  4. 提交结果：开赛20分钟后可上传截图 + 胜方 + KDA数据
  5. 管理员结算：审核无误后发放奖池，胜方按入场费占比瓜分

奖池规则

  • 总奖池 = 10人入场费之和
  • 胜方5人按个人入场费占比瓜分总奖池
  • 败方5人入场费全损，无返还
  • 报名不足10人 → 自动取消 → 全额退费

队伍系统

  • 可创建或加入队伍（最多7人）
  • 队长可邀请成员、踢人、转让、解散
  • 管理员也可代建队伍和调整成员

腾讯会议

  • 模式2（纯组织者）会自动创建会议
  • 其他模式下，发起人可手动创建会议

重要规则

  • 每条分路只能1人，全场最多10人
  • 可带朋友一起报名，无需注册多个账号
  • 满10人后进入确认阶段，未确认者不会占用位置
  • 确认成局后锁定，不再接受新报名
