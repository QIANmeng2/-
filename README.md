## 1. 平台简介

浅梦训练赛约队平台是一个面向王者荣耀玩家的训练赛组织工具，分为两大核心场景：

| 场景 | 适用人群 | 说明 |
|------|---------|------|
| **招募大厅** | 散人/散队 | 单人或多至4人组队，凑齐10人自动成局 |
| **档期广场** | 完整5人车队 | 发布档期等待对手队伍匹配 |

### 术语说明

- **BO1**: 单局决胜
- **BP**: 指全局BP模式（双方禁用/选择英雄）
- **分路**: 对抗路、打野、中路、发育路、游走
- **锁位**: 关闭=己方占坑（不招人），开启=对外开放报名

## 2. 快速入门

### 2.1 注册登录

1. 点击右上角「登录」按钮
2. 选择「注册」模式，填写以下信息：
   - 用户名（唯一标识）
   - 密码
   - 队伍名称（如：星河战队）
   - 名称/游戏ID
   - 微信号（用于联系）
   - 队伍等级（大众/KPL/K甲等）
   - 队伍备注（选填）

### 2.2 主界面导航

- **⚔️ 招募大厅**: 发布/加入散人对局
- **👥 我的队伍**: 管理自己的队伍（需先创建或加入）
- **📅 我的日程**: 查看发布的档期和申请记录
- **👤 个人信息**: 编辑个人/队伍资料
- **⚙️ 管理**: 管理员面板（仅管理员可见）

## 3. 招募大厅

> 适合：单人或多至4人朋友组队，凑齐10人自动成局

### 3.1 查看招募列表

招募大厅分为两个子标签：
- **🔥 招募中**: 正在开放报名的对局
- **✅ 已满专区**: 10人已凑齐的对局

每个招募卡片显示：
- 状态标签（招募中/已满）
- 段位要求
- 发起人信息
- 报名进度（X/10人）
- 红蓝双方各有多少人

### 3.2 加入对局

1. 点击想加入的对局卡片
2. 选择阵营（蓝方/红方）和分路
3. 点击「报名」按钮
4. 可随时撤销报名重新选择

**规则限制**：
- 每条分路只能有1人
- 全场最多10人
- 不能重复报名同一对局
- 发起人不能报名自己的对局

### 3.3 发起招募（新建对局）

1. 点击「➕ 新建招募」按钮
2. 填写以下信息：
   - **开赛时间**: 选择日期时间，或点击「即刻开打」
   - **段位门槛**: 不限/星耀/王者/荣耀王者
   - **自定义备注**: BP规则、开赛群号等
   - **联系群号**: 方便队员加群沟通
3. 选择发起人模式：
   - **模式1·我也要参赛**: 发起人也上场
   - **模式2·我只组织**: 发起人不参赛，纯组织
   - **模式3·我带部分队友**: 自带1-4人进来

### 3.4 满员自动成局

当红蓝双方各5人（共10人）全部凑齐时：
1. 系统自动锁定对局
2. 弹出「训练赛组队成功」提示
3. 参赛人员前往QQ/微信大群统一确认细节

### 3.5 腾讯会议功能

- **模式2**: 系统自动在赛前10分钟创建腾讯会议
- **其他模式**: 发起人可在对局详情页手动创建会议
- 创建后显示会议号和加入链接

## 4. 档期广场

> 适合：已经凑齐5人的完整车队，寻找对手队伍

### 4.1 发布档期

1. 在「📅 我的日程」页面
2. 选择日期和时间
3. 设置比赛模式（BO1）
4. 点击「发布档期」

### 4.2 管理档期

发布的档期有以下状态：

| 状态 | 说明 | 可执行操作 |
|------|------|-----------|
| 待匹配 | 等待其他队伍申请 | 取消发布 |
| 已确认 | 有队伍申请，等待确认 | 确认/拒绝申请 |
| 已成局 | 双方确认，等待开赛 | 修改时间/取消训练 |

### 4.3 申请对方档期

1. 在档期广场查看其他队伍发布的档期
2. 点击「申请」按钮
3. 等待对方队长确认

### 4.4 公开公示

确认后的训练赛可选择「公开公示」，让其他用户看到比赛结果。

## 5. 队伍系统

### 5.1 创建队伍

**方式一：用户自主创建**
1. 在「👥 我的队伍」页面
2. 点击「创建队伍」
3. 填写队伍名称和简介
4. 自动成为队长

**方式二：管理员创建（管理员功能）**
1. 进入管理面板 → 队伍管理
2. 点击「新建队伍」
3. 填写队伍名称、简介、最大人数
4. 可指定队长

### 5.2 队伍管理

**队长权限**：
- 修改队伍名称/简介
- 邀请成员加入
- 踢出成员
- 转让队长
- 解散队伍

**成员操作**：
- 查看队伍信息
- 退出队伍

### 5.3 招募中使用队伍

- 发起招募时可选择「带上我的队伍」
- 为队员分配阵营和分路
- 已分配的位置自动锁定不对外报名

### 5.4 队伍限制

- 每支队伍最多7人
- 每位用户只能加入一支队伍
- 加入新队伍会自动退出原队伍

## 6. 个人信息

### 6.1 可编辑信息

- **教练/联系人名称**: 用于展示和联系
- **微信号**: 联系方式
- **队伍等级**: 大众/KPL/K甲/青训等
- **队伍备注**: 队伍介绍

### 6.2 游戏资料

- **游戏ID**: 峡谷之巅ID
- **游戏服务器**: 手Q区/微信区
- **段位**: 钻石至巅峰赛分数
- **巅峰分数**: 最高分数
- **分路数据**: 各分路场次统计
- **英雄池**: 常用英雄列表

## 7. 管理员功能

> 仅管理员账户可见并可操作

### 7.1 仪表盘

管理面板首页显示：
- 总用户数
- 总档期数
- 总招募数
- 招募中/已满对局数
- 总队伍数
- 今日档期数

### 7.2 用户管理

- 查看所有用户列表
- 支持筛选：等级/服务器/段位/巅峰分/英雄池
- 支持搜索：用户名/教练名/游戏ID
- 按巅峰分排序
- 删除用户

### 7.3 招募管理

- 查看所有招募对局（所有状态）
- 查看每个对局的详细报名情况
- 删除招募对局

### 7.4 档期管理

- 查看所有档期
- 删除档期

### 7.5 队伍管理

- 查看所有队伍
- **新建队伍**: 创建队伍并可指定队长
- **编辑队伍**: 修改名称/队长/状态/人数上限
- **添加成员**: 将用户加入队伍
- **移除成员**: 从队伍移除用户
- 删除队伍

### 7.6 安全设置

- 查看管理员账户状态
- 安全建议提示

## 8. 常见问题

### Q1: 为什么我无法报名某个对局？
可能原因：
- 该对局已满员或已关闭
- 你是该对局的发起人
- 该分路已被他人占位
- 你已报名该对局（需先撤销）

### Q2: 如何取消已发布的招募？
作为发起人，在对局卡片上点击「撤销招募」即可删除。

### Q3: 如何退出当前队伍？
在「👥 我的队伍」页面点击「退出队伍」。

### Q4: 队长退出队伍后会发生什么？
队长退出后，队伍会自动转让给最早加入的成员。如果只剩队长一人，队伍将被解散。

### Q5: 如何设置腾讯会议？
- 模式2会自动创建
- 其他模式下，发起人可在对局详情页点击「创建会议」

### Q6: 满员后还能报名吗？
不能。满员后对局自动锁定，不再接受新报名。
